1. Run `bash scripts/new-skill.sh pdf-documents pdf-extractor` from repo root.
2. Remove the copied `package.json` (this is a Python-only skill).
3. Manual file creation (do NOT rely solely on scaffold for content):
   - `scripts/pdf_extractor.py` — implement:
     - `argparse` with `--input` (required), `--output-dir` (optional, defaults to input basename + `_extracted`), `--ocr` (flag).
     - Use `pdfplumber.open()` for text and table extraction per page.
     - Write extracted text as page-N.md files; extracted tables as page-N-table-M.csv.
     - If `--ocr` is set, use `pdf2image.convert_from_path()` to convert pages to PIL images, then invoke tesseract (or fall back gracefully if tesseract is unavailable).
     - Exit 0 on success; exit non-zero with stderr message on error.
   - `tests/test_pdf_extractor.py` — implement:
     - `fixture` that generates a tiny PDF with known text using a pure-Python approach (e.g., `reportlab` or inline bytes via `pdfplumber` + creation; if `reportlab` is not available, craft minimal PDF binary — simplest: skip real binary generation and mock `pdfplumber.open`).
     - Happy-path test: verify that when pdfplumber returns mock pages with text, the script writes markdown output correctly.
     - Failure-path test: non-existent input file → non-zero exit + stderr message.
     - All tests use `tmp_path` fixture from pytest; no internet access.
   - `SKILL.md` — write from scratch (don't keep template placeholder content):
     - Frontmatter: `name: pdf-extractor`, `description` matching the issue spec.
     - Sections: What it does, When to use, How to use, Examples (at least 1), Configuration (env vars table — none required).
   - `README.md` — install instructions, test instructions, optional OCR setup note.
   - `reference.md` — detailed output format spec, tesseract install for different OSes.
   - `requirements.txt` — `pdfplumber>=0.10`, `pdf2image>=1.16`, `Pillow>=10.0`, `pytest>=8.0`.
